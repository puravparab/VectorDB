### what is this?

This project is an attempt to build a fast and performant vector database.

### planned features

- [ ] core vector ops
	- [ ] vector storage (simple in-memory first)
	- [ ] euclidean distance
	- [ ] cosine similarity

- [ ] search
	- [ ] k-nearest neighbor
	- [ ] approximate nearest neighbor
	- [ ] hnsw

- [ ] queries
	- [ ] simple querying
	- [ ] filtered querying
	- [ ] batch querying

- [ ] metadata

- [ ] storage (save/load from disk)
